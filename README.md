# 📊 Sales Management & Customer Analysis using MySQL

## 📌 Project Overview

This project analyzes sales, customers, salespeople, and order transactions using MySQL. The objective is to extract meaningful business insights using SQL queries, joins, aggregations, subqueries, CTEs, CASE statements, and window functions.

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- GitHub

## 🗂️ Database Tables

### 1. Salespeople
Contains salesperson details such as:
- Salesperson ID
- Salesperson Name
- City
- Commission

### 2. Customers
Contains:
- Customer ID
- Customer Name
- City
- Salesperson ID

### 3. Orders
Contains:
- Order ID
- Order Date
- Order Amount
- Customer ID
- Salesperson ID

## 🔍 Key Analysis Performed

- Total sales calculation
- Average order value
- Highest and lowest orders
- Customer-wise sales analysis
- Salesperson-wise sales analysis
- City-wise sales analysis
- Monthly sales analysis
- Order count by salesperson
- High-value customer identification
- Salesperson ranking
- Data-quality checking
- NULL value analysis

## 💡 SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- CASE
- Subqueries
- CTEs
- Window Functions
- Date Functions

## 📈 Business Insights

The analysis helps identify high-performing salespeople, high-value customers, sales trends, order performance, and city-wise sales contribution.

## 🎯 Project Outcome

This project demonstrates practical SQL skills for Data Analyst, MIS Analyst, Reporting Analyst, Business Analyst, and Operations Analyst roles.
